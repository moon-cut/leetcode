# RNA逆向折叠中的双曲图神经网络（HGCN）落地流程

## 1. 任务定义
- **输入**：RNA二级结构（dot-bracket）如 `(((...)))`。
- **输出**：同长度RNA序列（`A/U/C/G`）如 `GCGAAACGC`。
- **建模方式**：把每个核苷酸位置看作图节点；主链相邻关系和碱基配对关系看作边。

## 2. 为什么用双曲空间
RNA二级结构（尤其包含发卡、内环、多分支环）天然包含明显的层级与树状拓扑。
在欧氏空间中表达这类“指数级扩展”的层级关系通常效率不高，而双曲空间可以用更低维度保持距离结构。

## 3. 端到端流程
1. **结构解析**：dot-bracket -> 图边（主链边 + 配对边）。
2. **节点初始化**：位置嵌入/结构嵌入（可扩展加入SHAPE或能量特征）。
3. **映射到双曲空间**：`expmap0`。
4. **双曲消息传递**：在切空间聚合邻居，再映射回Poincaré球。
5. **输出层**：回到切空间，用线性层输出4类碱基logits。
6. **训练**：逐位交叉熵 +（可选）GC含量、配对一致性约束。
7. **推理**：argmax 或 beam search 生成序列。

## 4. 建议的数据与损失增强
- **数据来源**：Rfam、bpRNA、RNASTRAND 等。
- **增强损失**：
  - 配对位点互补惩罚（AU/UA/CG/GC/GU/UG）。
  - 结构回折一致性（把预测序列送入ViennaRNA/MXfold2，约束与目标结构一致）。
  - 温度采样增强，减少模式坍缩。

## 5. 代码映射
- `rna_hgcn/structure.py`：dot-bracket解析与图构建。
- `rna_hgcn/hyperbolic_layers.py`：Poincaré球操作 + HGCN层。
- `rna_hgcn/model.py`：逆向折叠模型。
- `rna_hgcn/data.py`：样本与图张量转换。
- `train_rna_hgcn.py`：最小可运行训练脚本。

## 6. 从HazyResearch/HGCN迁移时的关键点
- 保留“**切空间聚合 + 双曲映射**”主干思想。
- 根据RNA任务改造输入图与输出头，而不是直接复用节点分类头。
- 先用小规模数据验证收敛，再加入结构一致性损失与解码策略。
